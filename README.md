# Study Planner

Вебзастосунок для планування навчальних завдань: створення, редагування й видалення завдань із можливістю скасування, фільтрація за статусом, статистика та збереження даних у браузері.

🔗 **Демо проєкту:** https://study-planner-pied-nine.vercel.app

## Використані технології
* **Frontend:** React 19, TypeScript (`useReducer`, Context API, власні хуки)
* **Стилізація:** SCSS, методологія BEM (стилі кожного компонента лежать поруч із ним)
* **Робота з даними:** `localStorage` (завдання та фільтр зберігаються між сеансами)
* **Збірка:** Vite
* **Якість коду:** ESLint (`typescript-eslint`, `react-hooks`)

## Основний функціонал
* Додавання та редагування завдань (одна форма, два режими): назва, опис, категорія, пріоритет (низький / середній / високий).
* Відмітка завдання виконаним.
* Видалення з можливістю скасування: завдання на 5 секунд стає «Буде видалено», з'являється Toast із прогресом і кнопкою «Скасувати».
* «Очистити виконані» через той самий механізм скасування; «Скинути дані» з підтвердженням.
* Фільтрація списку: всі / виконані / не виконані.
* Статистика: всього, виконано, не виконано.
* Toast-сповіщення про результат дій з автозакриттям.
* Збереження завдань і фільтра в `localStorage`; при пошкоджених даних застосунок повертається до початкового списку.
* Кількість невиконаних завдань у заголовку вкладки.

## Як це працює
* **Стан.** Список завдань керується `taskReducer` (дії `add`, `toggle`, `update`, `requestDelete`, `confirmDelete`, `undoDelete`, `clearCompleted`, `reset`); він не містить таймерів, DOM чи `localStorage`. Відфільтрований список і статистика рахуються під час рендеру.
* **Context.** `TaskProvider` надає компонентам дані та операції, тож через props вони не передаються.
* **Undoable Delete.** `requestDelete` лишає завдання в масиві, але позначає його як очікуване видалення. Через 5 с таймер викликає `confirmDelete`, а «Скасувати» викликає `undoDelete`. Одночасно діє одне видалення.

## Як запустити локально
Потрібен Node.js 22.22 або новіший.

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/<ваш-логін>/study-planner.git
   ```
2. Перейдіть у папку проєкту та встановіть залежності:
   ```bash
   cd study-planner
   npm install
   ```
3. Запустіть сервер для розробки:
   ```bash
   npm run dev
   ```
